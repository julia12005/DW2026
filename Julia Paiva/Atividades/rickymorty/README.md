# Rick and Morty App

Aplicação desenvolvida com Vue 3 e Vue CLI para listar personagens da API pública de Rick and Morty.

## Funcionalidades

- Listagem de personagens em cards responsivos
- Nome, foto e última localização conhecida
- Indicador visual de status: vivo, morto ou desconhecido
- Paginação com botões Anterior e Próxima
- Estados de carregamento e erro

## Tecnologias

- Vue 3
- Vue CLI
- JavaScript
- CSS responsivo
- Rick and Morty API

## Como executar

1. Instale o Node.js, caso ainda não esteja instalado.
2. Abra o terminal dentro desta pasta.
3. Execute `npm install`.
4. Execute `npm run serve`.
5. Abra no navegador o endereço exibido pelo terminal, normalmente `http://localhost:8080`.

## Build de produção

Execute `npm run build`.

## Endpoint utilizado

`https://rickandmortyapi.com/api/character?page=1`

## Prints para entrega

Inclua no envio:

1. Tela completa com a listagem dos personagens em cards.
2. Imagem destacando os indicadores de status vivo, morto e desconhecido.
